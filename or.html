Q1: Formulation of LPP

A milk plant manufactures two types of products A and B... Formulate the problem for maximizing profit.

Step 1: Identify Decision Variables
Let x₁ be the number of units produced of product type A.
Let x₂ be the number of units produced of product type B.

Step 2: Formulate the Objective Function
The profit is Rs. 5 on type A and Rs. 3 on type B. The goal is to maximize total profit.
Maximize Z = 5x₁ + 3x₂

Step 3: Formulate Constraints
Convert available machine times from hours/minutes to total minutes:
• Machine G: 6 hours 40 minutes = (6 × 60) + 40 = 400 minutes
• Machine H: 8 hours 20 minutes = (8 × 60) + 20 = 500 minutes

Product A requires 1 min on G and 2 mins on H. Product B requires 1 min on G and 1 min on H.
• Constraint for Machine G: x₁ + x₂ ≤ 400
• Constraint for Machine H: 2x₁ + x₂ ≤ 500

Step 4: Non-negativity Restriction
Production cannot be negative.
x₁, x₂ ≥ 0

Final LP Model:

Maximize Z = 5x₁ + 3x₂

Subject to:

x₁ + x₂ ≤ 400

2x₁ + x₂ ≤ 500

x₁, x₂ ≥ 0

Q4: Graphical Method

Solve LPP: Maximize Z = 8x + y. Subject to: x + y ≤ 40, 2x + y ≤ 60.

Objective: Maximize Z = 8x + y

Step 1: Find coordinates for the constraint lines.
Line 1 (x + y = 40):
If x = 0, y = 40 → Point: (0, 40)
If y = 0, x = 40 → Point: (40, 0)

Line 2 (2x + y = 60):
If x = 0, y = 60 → Point: (0, 60)
If y = 0, x = 30 → Point: (30, 0)

Step 2: Find intersection point of the two lines.
Subtract Line 1 from Line 2:
(2x + y) - (x + y) = 60 - 40
x = 20
Substitute x = 20 into Line 1:
20 + y = 40 ⇒ y = 20
Intersection point: (20, 20)

Step 3: Evaluate objective function at feasible corner points.

Corner Point (x, y) Value of Z = 8x + y
(0, 0)8(0) + 0 = 0
(30, 0)8(30) + 0 = 240
(20, 20)8(20) + 20 = 180
(0, 40)8(0) + 40 = 40

Conclusion: The maximum value of Z is 240, which occurs at coordinates x = 30, y = 0.

Q7: Simplex Method (Initial Table)

Construct the initial simplex table for: Max Z = 3x₁ + 2x₂ + 4x₃

Step 1: Convert inequalities to equations by introducing slack variables (s₁, s₂, s₃)

Maximize Z = 3x₁ + 2x₂ + 4x₃ + 0s₁ + 0s₂ + 0s₃

Subject to:
x₁ + x₂ + x₃ + s₁ = 6
2x₁ + x₂ + 3x₃ + s₂ = 9
x₁ + 2x₂ + x₃ + s₃ = 8
x₁, x₂, x₃, s₁, s₂, s₃ ≥ 0

Step 2: Construct the Initial Simplex Table

CB Basis Cj → 3 2 4 0 0 0 RHS (b) Ratio
Variables → x₁ x₂ x₃ s₁ s₂ s₃
0 s₁ 1 1 1 1 0 0 6 6/1 = 6
0 s₂ 2 1 3 (Pivot) 0 1 0 9 9/3 = 3 ← (Leaving)
0 s₃ 1 2 1 0 0 1 8 8/1 = 8
Zj = Σ(CB × Xj) 0 0 0 0 0 0 Z = 0
Δj = Zj - Cj -3 -2 -4 ↑ (Entering) 0 0 0

Conclusion: The most negative Δj is -4, meaning x₃ is the entering variable. The minimum positive ratio is 3, making s₂ the leaving variable. The pivot element is 3.

Q1: North-West Corner (NWC) Method

Solve the transportation problem using NWC Method. Find initial cost and check degeneracy.

Problem Data:
Supply (S₁, S₂, S₃): 20, 30, 25 (Total = 75)
Demand (D₁, D₂, D₃): 10, 35, 30 (Total = 75)
The problem is balanced since Total Supply = Total Demand.

Step 1: Allocate starting from the top-left (North-West) cell.
1. Cell (S₁, D₁): Supply is 20, Demand is 10. Allocate 10. D₁ satisfied. Remaining S₁ = 10.
2. Cell (S₁, D₂): Remaining S₁ is 10, Demand is 35. Allocate 10. S₁ exhausted. Remaining D₂ = 25.
3. Cell (S₂, D₂): Supply is 30, Remaining Demand is 25. Allocate 25. D₂ satisfied. Remaining S₂ = 5.
4. Cell (S₂, D₃): Remaining S₂ is 5, Demand is 30. Allocate 5. S₂ exhausted. Remaining D₃ = 25.
5. Cell (S₃, D₃): Remaining S₃ is 25, Remaining Demand is 25. Allocate 25. Both satisfied.

Step 2: Calculate Initial Transportation Cost
Total Cost = (10 × 4) + (10 × 6) + (25 × 5) + (5 × 7) + (25 × 5)

Q3: Vogel's Approximation Method (VAM)

Solve the transportation problem using VAM. Find initial cost and check degeneracy.

Problem Data:
Supply (S₁, S₂, S₃): 25, 35, 30 (Total = 90)
Demand (D₁, D₂, D₃): 20, 30, 40 (Total = 90)
Problem is balanced.

Step 1: Calculate initial row and column penalties (difference between two lowest costs).
• Row Penalties: R1 (7-3=4), R2 (6-4=2), R3 (6-5=1)
• Col Penalties: C1 (5-4=1), C2 (6-3=3), C3 (7-6=1)
Max penalty is 4 in Row 1. Minimum cost in Row 1 is 3 at cell (S₁, D₂). Allocate min(25, 30) = 25 units. S₁ is exhausted. Remaining D₂ = 5.

Step 2: Recalculate penalties ignoring Row 1.
• Row Penalties: R2 (6-4=2), R3 (6-5=1)
• Col Penalties: C1 (5-4=1), C2 (7-6=1), C3 (9-6=3)
Max penalty is 3 in Column 3. Minimum cost in Col 3 is 6 at cell (S₃, D₃). Allocate min(30, 40) = 30 units. S₃ is exhausted. Remaining D₃ = 10.

Step 3: Final Allocations (Only Row 2 remaining).
Allocate remaining demands directly to S₂:
(S₂, D₁) gets 20 units.
(S₂, D₂) gets 5 units.
(S₂, D₃) gets 10 units.

Q1: Hungarian Method (Minimization)

Solve the assignment problem and determine the minimum total cost.

Step 1: Row Reduction
Subtract the minimum element of each row from all elements in that row.
• Row 1 min = 2: (9-2, 2-2, 7-2) → (7, 0, 5)
• Row 2 min = 3: (6-3, 4-3, 3-3) → (3, 1, 0)
• Row 3 min = 1: (5-1, 8-1, 1-1) → (4, 7, 0)

Step 2: Column Reduction
Subtract the minimum element of each column from all elements in that column.
• Col 1 min = 3: (7-3, 3-3, 4-3) → (4, 0, 1)
• Col 2 min = 0: Remains unchanged.
• Col 3 min = 0: Remains unchanged.

Worker J₁ J₂ J₃
W₁40 (Assign)5
W₂0 (Assign)10 (Cross)
W₃170 (Assign)

Step 3: Draw minimum lines to cover all zeros.
• Line 1: Column 2 (covers zero at W₁, J₂)
• Line 2: Row 2 (covers zeros at W₂, J₁ and W₂, J₃)
• Line 3: Column 3 (covers zero at W₃, J₃)
Total lines = 3. Since number of lines equals matrix dimension (N=3), the solution is optimal.

Step 4: Optimal Assignments & Minimum Cost
• W₁ → J₂ (Cost = 2)
• W₂ → J₁ (Cost = 6)
• W₃ → J₃ (Cost = 1)
Minimum Total Cost = 2 + 6 + 1 = 9
