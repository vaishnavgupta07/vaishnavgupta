Q4, Q5, Q6. MODI Method (Optimality Check)

Q4 Check: Using u_i + v_j = C_ij for basic cells. For empty cell (S1,D3), Δij = C_ij - (u_i + v_j) = 8 - 10 = -2. Since Δij < 0, it is NOT optimal.

Q5 Check: The given basic feasible solution forms a closed loop, meaning it's invalid/degenerate. A proper basic feasible solution is required before MODI can be applied.

Q6 Check: Evaluating empty cells gives all Δij ≥ 0. (e.g., S1D3 = 4, S2D1 = 5, S3D1 = 3, S3D2 = 3). Since all values are positive, the given solution IS Optimal.
